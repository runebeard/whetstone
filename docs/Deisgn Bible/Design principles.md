Whetstone Principles
Player-first, not DM-first.
Mobile-first, not paper-first.
Context over categories.
Combat is a state, not a page.
Everything should be one or two taps away.
Homebrew is a first-class citizen.
Players own the rules; Whetstone manages the experience.
Data should be imported whenever possible rather than manually entered.
Multiple characters are supported from day one.
The app should work completely offline.



Progressive Discovery
    The interface should be clean by default.
    Advanced interactions shouldn't require permanent buttons.
    Every interactive element can explain itself.
    Require player to tap element to move on to the next.
    Help is always available.
    The user is never trapped in a tutorial.


## Interaction

Tap = Gameplay

Long Press = Configuration

## Visual Hierarchy

Large centred number boxes.

Primary actions use DialogueActionButton.

Secondary actions use text buttons.

## Philosophy

Optimise for speed at the table.

Manual entry first.

Automation later.


## Don't make the player repeat work the app can remember.

That applies everywhere.
Examples:
Remember previously owned items.
Remember edited AC.
Remember HP maximum.
Remember favourite actions.
Remember spell preparation.
Every time we can save the player from re-entering something, we should.
