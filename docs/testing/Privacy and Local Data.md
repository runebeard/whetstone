# Privacy and Local Data - Alpha 0.1.0

Whetstone Alpha does not require an account and does not include analytics,
advertising, tracking, or an application internet permission in its Android
release build.

Characters, live health and resources, inventory, journals, installed content
packs, settings, and Session Timelines are stored in Whetstone's private app
storage on the device.

Whetstone only places character packages or Vault Backups outside that private
storage when the player deliberately copies or exports them. Exported text can
contain character and campaign information and should be handled accordingly.
The operating system clipboard may be visible to other applications.

Device operating-system backup services may separately back up application
data according to the device owner's settings. Whetstone does not control or
transmit those backups itself.

Uninstalling Whetstone or clearing its app storage can remove the local Vault.
Players should create a full Vault Backup first and keep the copied package in
a trusted location. Whetstone Alpha has no remote account from which lost data
can be recovered.
