# Whetstone Friend Test - Alpha 0.1.0

Thank you for helping test Whetstone. This is an early, offline character
companion for tabletop roleplaying games. The aim of this test is to discover
what feels natural, what causes hesitation, and what breaks during real play.

## Before installing

- This build is an alpha, not a finished or store-reviewed app.
- Android may warn that the app came from outside the Play Store. Only install
  the APK received directly from the Whetstone project owner.
- Whetstone does not require an account or internet connection.
- Your characters are stored on your device. Make a **Vault Backup** before
  uninstalling, clearing app storage, changing phones, or installing a build
  that you are uncertain about.

## Suggested test journey

Please try this without asking for instructions unless you become stuck:

1. Open Whetstone and choose either character creation or the sample party.
2. Find a skill and make a roll.
3. Start combat, make an attack and damage roll, spend a resource, and end
   combat.
4. Add or edit a spell, feature, item, or journal entry.
5. Close Whetstone completely, reopen it, and confirm your changes remain.
6. Return to the Vault and create a full Vault Backup.
7. If you are comfortable doing so, restore that backup and check the result.

You do not need to test everything. Normal play and honest confusion are more
valuable than trying to behave like a software tester.

## What to notice

- Where did you instinctively tap first?
- Did any wording make you stop and think?
- Did information appear where you expected it during play?
- Did anything require too many taps?
- Did anything look tappable but fail to respond?
- Were any controls cramped, cut off, or difficult to read?
- Did you ever worry that you might lose character data?

## Reporting feedback

Use the accompanying `Feedback Form.md`, send notes directly to the project
owner, or create an issue at:

https://github.com/runebeard/whetstone/issues

Screenshots are extremely helpful. Please remove private campaign notes before
sharing a screenshot or exported character package publicly.
